# HairSoft Klient V151

V151 dolaďuje sekci **Uživatelé** nad V150.

## Překlady importu
- CZ: **Import obsluh z HairSoft**
- SK: **Import obslúh z HairSoft**
- EN: **Import staff from HairSoft**
- DE: **Mitarbeiter aus HairSoft importieren**

## Detail obsluhy
- profilová fotografie už není v samostatné vysoké kartě,
- fotografie a jméno jsou kompaktně uvnitř společné karty **Detail obsluhy**,
- přístupové údaje a hodnocení zůstávají ve stejné kartě,
- **Oprávnění obsluhy** jsou pod detailem přes celou dostupnou šířku,
- mobilní zobrazení skládá profil nad formulář bez velkých prázdných ploch.

## Bezpečnost
- bez změn SQL a databáze,
- bez změn názvů formulářových polí, POST/GET hodnot a akcí,
- bez změn logiky hesel, oprávnění, anonymizace, archivace, mazání a importu.
