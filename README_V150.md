# HairSoft Klient V150

V150 je drobná UI oprava sekce **Uživatelé** nad V149.

## Spodní horizontální posuvníky
- u tabulek aktivních i archivovaných obsluh je zvětšen spodní bezpečný odstup mezi stránkováním a horizontálním posuvníkem,
- posuvník už opticky neleží těsně pod tlačítky stránkování,
- na mobilním kartovém zobrazení se tento dodatečný odstup nepoužívá.

## Beze změny
- datová logika, SQL, práva, hesla, archivace, mazání a import,
- rozložení horního výběru pobočky a importu,
- tabulky, hledání, stránkování a překlady.

`users.css` používá cache verzi V150.
