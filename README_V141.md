# HairSoft Klient V141

Kompletní balíček navazuje na V140.
Po načtení editace existující otázky se stránka posune na první řádek editoru s textem otázky. Respektuje horní lištu. Běžné otevření nastavení bez editace stránku neposouvá. Na mobilu se automaticky neotevírá klávesnice.
Formuláře a ukládání zůstávají beze změny.

Nahrajte hs-client-ui a str, původní soubory ponechte. Potom Ctrl+F5.
