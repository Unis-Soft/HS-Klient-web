# V157 – Uživatelé: detail obsluhy – vyplnění prostoru

- Horní detail obsluhy používá na desktopu celý dostupný prostor stejně jako dvojice bloků v sekci SMS.
- Levý blok (profil + přístupové údaje) a pravý blok (nastavení hodnocení) mají na desktopu stejnou výšku.
- Odstraněno předchozí omezení šířky 1120 px, které vytvářelo zbytečně prázdné okraje.
- Nastavení hodnocení je rozděleno na dvě samostatné karty/řádky s mezerou mezi nimi.
- Na tabletu a mobilu se oba hlavní bloky skládají pod sebe; výška není vynucená.
- Oprávnění, PHP formuláře, POST/SQL logika a databázové operace zůstávají beze změny.
