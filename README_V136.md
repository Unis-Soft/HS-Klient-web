# HairSoft Klient V136
Pod rozbalenou poznámkou je decentní tlačítko Uložit, přeložené do CS/SK/EN/DE. Odesílá stejný formulář jako Uložit změny v Informacích, tedy poznámku i další údaje karty. Je dostupné také ze Soubory a ostatních záložek. Následuje původní průběh uložení stránky. U mobilní poznámky zvětšen prostor pro tlačítko i při dlouhém textu.

Obsahuje všechny opravy V135. Nahrajte hs-client-ui a str, původní str/strana ponechte. Potom Ctrl+F5.
Ověřeno v Chrome při šířkách 390 a 1366: odeslání správného formuláře, GUID, akce edit a textu poznámky ze záložky Soubory; tlačítko není oříznuté ani u dlouhé poznámky. Bez změn PHP ukládání. Živá databáze nebyla měněna.
