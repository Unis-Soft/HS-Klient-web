# HS Klient V233 – česká diakritika v názvu Programu

V233 navazuje na V232 a opravuje ořezávání horních částí českých velkých znaků v názvu Programu (zejména Ě).

- Název v seznamu zákazníků dostal větší vertikální prostor a font s plnou českou diakritikou.
- Totéž platí pro název programu v detailu zákazníka.
- Logika seznamu se nemění: jeden program = název sloupce, dlouhý název = zkrácení s výpustkou, více programů = výběrové combo v hlavičce sloupce.
- Grafy a HSBridge V010 se ve V233 nemění.
