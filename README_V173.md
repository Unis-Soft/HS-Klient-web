# HairSoft Klient V173

Výchozí stav: V172.

## Změny

1. **Celý řádek / karta obsluhy otevírá detail**
   - na PC lze otevřít detail kliknutím kamkoli na datový řádek obsluhy,
   - na mobilu je klikací celá karta, ne pouze profilová fotografie,
   - odkazy a tlačítka v buňce Akce zůstávají samostatné a nespouštějí otevření detailu,
   - přidána je i klávesnicová aktivace řádku Enter/Mezerník.

2. **Archivované obsluhy jsou výchozí sbalené**
   - panel Seznam archivovaných obsluh je po načtení stránky sbalený,
   - admin jej rozbalí tlačítkem v hlavičce nebo kliknutím na hlavičku panelu,
   - na mobilu je přepínač záměrně kompaktní pouze jako šipka,
   - po rozbalení se přepočítají šířky DataTables, aby skrytá inicializace nerozbila tabulku,
   - použity jsou již existující překlady „Zobrazit archivované / Skrýt archivované“ pro CZ/SK/EN/DE.

Databáze, formuláře, práva, hesla, archivace i ostatní obchodní logika se nemění.
