# V164 – Docházka: pravé zakončení tabulky

- Opraven skutečný pravý okraj tabulky Docházky.
- Odstraněno neúčinné zúžení wrapperu z V163.
- Pravý border se nyní kreslí přímo na poslední buňce každého řádku (thead/tbody/tfoot), takže je viditelný po celé výšce tabulky.
- Doplněno správné zakulacení pravého horního a dolního rohu.
- Přidána 2px bezpečnostní rezerva ve scroll wrapperu, aby prohlížeč pravý border neořízl.
- Datová logika, exporty, PDF, filtry a mobilní zobrazení beze změny.
