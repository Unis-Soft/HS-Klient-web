# HairSoft Klient V175

Výchozí verze: V174.

## Číselník pojišťoven
- nový moderní override `hs-client-ui/php/strana/NastaveniCiselnikPojistoven.php`,
- Voucher-style tabulka se zaoblením, střídáním řádků a čistými ikonovými akcemi,
- Hledat vlevo, stránkování dole,
- mobilní karty podle aktuální DataTables stránky a filtru,
- moderní formulář pro přidání/editaci pojišťovny,
- společný HairSoft potvrzovací dialog při mazání,
- překlady CZ/SK/EN/DE.

Databázová logika a tabulka `cislenik_pojistovny` se nemění. Napojení `KartaOsoby.php` pro nového i stávajícího zákazníka zůstává beze změny.
