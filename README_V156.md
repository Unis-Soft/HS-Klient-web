# HairSoft Klient V156

## Uživatelé – nový detail obsluhy
- Horní detail obsluhy je znovu navržen jako nová kompaktní komponenta.
- Profil již netvoří samostatný sloupec ani velkou plochu; je součástí hlavní karty účtu.
- Přístupové údaje zůstávají ve dvou polích vedle sebe na desktopu, na mobilu pod sebou.
- Nastavení hodnocení je samostatná kompaktní karta vedle účtu; na tabletu/mobilu se skládá pod účet.
- Oprávnění obsluhy z V154/V155 se nemění.
- Interní login zůstává skrytý.
- Form action, hidden hodnoty, názvy/ID polí, hodnocení auto-submit, SQL a databáze se nemění.
